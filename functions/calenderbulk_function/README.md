# Calendar Bulk Function API

This function provides a complete backend API for managing calendar bulk data in the Statutory Management System. It handles CRUD operations for the "Calenderbulk" table in the Data Store.

## Data Structure

The calendar bulk data follows this structure based on the Data Store schema:

```javascript
{
  id: "ROWID",                    // Auto-generated by Data Store
  sNo: "1",                       // Serial Number
  forms: "Form 3",                // Form name/type
  sector: "Manufacturing",        // Industry sector
  description: "Construction Permission", // Description of the requirement
  rules: "Rule 3",                // Associated rule number
  schedule: "Permission to be obtained...", // Schedule description
  jan: "",                        // January deadline (day of month)
  feb: "",                        // February deadline
  mar: "",                        // March deadline
  apr: "",                        // April deadline
  may: "",                        // May deadline
  june: "",                       // June deadline
  july: "",                       // July deadline
  aug: "31",                      // August deadline
  sep: "",                        // September deadline
  oct: "",                        // October deadline
  nov: "",                        // November deadline
  dec: ""                         // December deadline
}
```

## API Endpoints

### Base URL
```
/server/calenderbulk_function/calenderbulk
```

### 1. Get All Calendar Bulk Data
**GET** `/server/calenderbulk_function/calenderbulk?action=getAll`

Returns all calendar bulk records from the Data Store.

**Response:**
```json
{
  "status": "success",
  "message": "Calendar bulk data retrieved successfully",
  "data": [...],
  "count": 8
}
```

### 2. Get Calendar Bulk Data by ID
**GET** `/server/calenderbulk_function/calenderbulk?action=getById&id={ROWID}`

Returns a specific calendar bulk record by its ROWID.

**Parameters:**
- `id` (required): The ROWID of the record to retrieve

**Response:**
```json
{
  "status": "success",
  "message": "Calendar bulk data retrieved successfully",
  "data": {...}
}
```

### 3. Add New Calendar Bulk Data
**POST** `/server/calenderbulk_function/calenderbulk?action=add`

Adds a new calendar bulk record to the Data Store.

**Request Body:**
```json
{
  "sNo": "1",
  "forms": "Form 3",
  "sector": "Manufacturing",
  "description": "Construction Permission",
  "rules": "Rule 3",
  "schedule": "Permission to be obtained...",
  "jan": "",
  "feb": "",
  "mar": "",
  "apr": "",
  "may": "",
  "june": "",
  "july": "",
  "aug": "31",
  "sep": "",
  "oct": "",
  "nov": "",
  "dec": ""
}
```

**Response:**
```json
{
  "status": "success",
  "message": "Calendar bulk data added successfully",
  "data": {
    "id": "28341000000065159",
    "sNo": "1",
    "forms": "Form 3",
    ...
  }
}
```

### 4. Update Calendar Bulk Data
**PUT** `/server/calenderbulk_function/calenderbulk?action=update&id={ROWID}`

Updates an existing calendar bulk record.

**Parameters:**
- `id` (required): The ROWID of the record to update

**Request Body:** Same structure as add request

**Response:**
```json
{
  "status": "success",
  "message": "Calendar bulk data updated successfully",
  "data": {...}
}
```

### 5. Delete Calendar Bulk Data
**DELETE** `/server/calenderbulk_function/calenderbulk?action=delete&id={ROWID}`

Deletes a calendar bulk record from the Data Store.

**Parameters:**
- `id` (required): The ROWID of the record to delete

**Response:**
```json
{
  "status": "success",
  "message": "Calendar bulk data deleted successfully"
}
```

### 6. Bulk Import Calendar Data
**POST** `/server/calenderbulk_function/calenderbulk?action=bulkImport`

Imports multiple calendar bulk records at once.

**Request Body:** Array of calendar bulk objects
```json
[
  {
    "sNo": "1",
    "forms": "Form 3",
    "sector": "Manufacturing",
    ...
  },
  {
    "sNo": "2",
    "forms": "Form 4",
    "sector": "Manufacturing",
    ...
  }
]
```

**Response:**
```json
{
  "status": "success",
  "message": "Bulk import completed successfully. 8 records added",
  "data": [...]
}
```

### 7. Get Calendar Data by Sector
**GET** `/server/calenderbulk_function/calenderbulk?action=getBySector&sector={SECTOR}`

Returns all calendar bulk records for a specific sector/industry.

**Parameters:**
- `sector` (required): The sector name to filter by (e.g., "Manufacturing", "Healthcare")

**Response:**
```json
{
  "status": "success",
  "message": "Calendar data for sector 'Manufacturing' retrieved successfully",
  "data": [...],
  "count": 5
}
```

### 8. Get Calendar Bulk Data Count
**GET** `/server/calenderbulk_function/calenderbulk?action=count`

Returns the total count of calendar bulk records.

**Response:**
```json
{
  "status": "success",
  "message": "Calendar bulk data count retrieved successfully",
  "count": 8
}
```

## Error Responses

All endpoints return error responses in this format:

```json
{
  "status": "error",
  "message": "Error description",
  "error": "Detailed error message"
}
```

## Usage Examples

### Frontend Integration

```javascript
// Fetch all calendar bulk data
const fetchCalendarData = async () => {
  try {
    const response = await fetch('/server/calenderbulk_function/calenderbulk?action=getAll');
    const result = await response.json();
    
    if (result.status === 'success') {
      console.log('Calendar data:', result.data);
      return result.data;
    } else {
      console.error('Error:', result.message);
    }
  } catch (error) {
    console.error('Network error:', error);
  }
};

// Add new calendar data
const addCalendarData = async (data) => {
  try {
    const response = await fetch('/server/calenderbulk_function/calenderbulk?action=add', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
      },
      body: JSON.stringify(data)
    });
    
    const result = await response.json();
    return result;
  } catch (error) {
    console.error('Error adding data:', error);
  }
};

// Get data by sector
const getDataBySector = async (sector) => {
  try {
    const response = await fetch(`/server/calenderbulk_function/calenderbulk?action=getBySector&sector=${encodeURIComponent(sector)}`);
    const result = await response.json();
    return result;
  } catch (error) {
    console.error('Error fetching by sector:', error);
  }
};
```

## Dependencies

- `zcatalyst-sdk-node`: Latest version for Data Store operations

## Notes

- All month fields (jan, feb, mar, etc.) store the day of the month as a string
- Empty month fields should be passed as empty strings ("")
- The ROWID is automatically generated by the Data Store
- Sector names are case-sensitive in queries
- The function handles both individual and bulk operations efficiently
